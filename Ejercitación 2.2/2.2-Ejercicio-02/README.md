En este ejercicio se define la clase Videojuego con los atributos titulo, plataforma y precio, que permiten representar las características principales de un videojuego.

Se implementa un constructor parametrizado para inicializar los atributos al momento de crear cada objeto, utilizando this para diferenciar los atributos de la clase de los parámetros recibidos.

En el método main se crean tres instancias diferentes de Videojuego, cada una con sus propios valores. Finalmente, se utiliza String.format() para construir una descripción de cada videojuego, utilizando %s para los valores de tipo String y %.2f para mostrar el precio como un número decimal con dos posiciones. De esta manera, se obtiene una salida ordenada y con un formato uniforme para las tres instancias.
