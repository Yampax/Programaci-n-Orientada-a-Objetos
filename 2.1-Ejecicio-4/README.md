En este ejercicio implementé una clase llamada Calculadora, en la cual desarrollé cuatro métodos de instancia para realizar las operaciones matemáticas básicas: suma, resta, multiplicación y división.

En cada uno de los métodos utilicé dos parámetros de tipo double, ya que de esta manera las operaciones pueden trabajar tanto con números enteros como con números decimales. Para almacenar temporalmente el resultado utilicé una variable auxiliar llamada aux, a la cual le asigné el resultado de la operación antes de retornarlo mediante return.

Para el método de división incorporé una estructura condicional if/else con el objetivo de controlar la división por cero. Primero verifico si el segundo parámetro (B), que representa al divisor, es igual a cero. Si lo es, muestro un mensaje indicando que no se puede realizar la operación. En caso contrario, realizo la división normalmente.

Finalmente, en el método main puedo crear una instancia de la clase Calculadora y utilizar sus métodos para realizar las diferentes operaciones. De esta manera, puse en práctica el uso de clases, métodos, parámetros, valores de retorno, variables auxiliares y estructuras condicionales.
