En este ejercicio se define una clase llamada Persona, que representa el modelo de una persona mediante dos atributos: nombre, de tipo String, y edad, de tipo int.

Luego se crean dos objetos (persona1 y persona2) utilizando la palabra reservada new. De esta manera se demuestra el proceso de instanciación, donde a partir de una misma clase se pueden crear diferentes objetos, cada uno con sus propios valores.

Finalmente, se asignan datos diferentes a cada objeto y se muestran por pantalla mediante System.out.println().
