En este ejercicio se define la clase ConsolaRetro con los atributos modelo, numeroSerie y encendida, utilizando un valor booleano para representar si la consola está encendida o apagada. Al ser un atributo de tipo boolean de instancia, encendida comienza con el valor false por defecto.

Se implementa un constructor parametrizado que permite establecer el modelo y el número de serie al momento de crear una instancia, utilizando this para asignar correctamente los valores recibidos a los atributos correspondientes.

También se implementan los métodos encender() y apagar(), que modifican el estado de la consola mediante los valores true y false. El método mostrarEstado() utiliza una estructura condicional if/else para comprobar el valor de encendida y mostrar por consola si la consola está encendida o apagada.

Finalmente, en el método main se crea una instancia de ConsolaRetro y se realiza una secuencia completa de comprobación, encendido, comprobación, apagado y comprobación nuevamente, demostrando el funcionamiento de los métodos y el cambio de estado del objeto.
