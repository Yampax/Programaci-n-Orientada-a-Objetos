En este ejercicio se diseñó la clase Mascota, definiendo tres atributos de instancia: nombre de tipo String, especie de tipo String y edad de tipo int. Estos atributos permiten representar las características básicas de cada objeto mascota.

Se implementó un constructor parametrizado que recibe el nombre, la especie y la edad como parámetros. Dentro del constructor se utilizó la referencia this para diferenciar los atributos de la instancia de los parámetros recibidos y asignar correctamente sus valores.

En el método main se crearon tres instancias diferentes de la clase Mascota mediante el operador new, pasando los valores correspondientes al constructor. De esta manera, cada objeto se crea directamente con sus atributos inicializados.

Finalmente, se utilizó System.out.println() junto con la concatenación de cadenas y el operador "." para acceder a los atributos de cada objeto y mostrar por pantalla la información de las tres mascotas.
